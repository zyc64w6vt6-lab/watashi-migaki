わたし磨きノート — iPhone向けPWA

内容:
- 食事・生活習慣チェック
- 満腹でも食べたくなる気持ちやきっかけの記録
- 日別履歴、編集、削除
- 7日間の習慣進捗、JSON書き出し
- 端末のブラウザ内保存（localStorage）

iPhoneのホーム画面に追加する方法:
1. このフォルダ内のファイル一式をHTTPS対応の静的ホスティングにアップロードしてください。
2. iPhoneのSafariで公開されたURLを開きます。
3. 共有ボタン →「ホーム画面に追加」→「追加」。

重要:
- index.htmlをファイルアプリから直接開くだけでは、PWAとしてのホーム画面追加やオフライン機能が動作しない場合があります。
- 記録は利用中のブラウザ内に保存されます。ブラウザデータを消すと記録が消えることがあります。履歴画面の「データを書き出す」でバックアップしてください。
- 医療的な診断・治療の代わりではありません。
